# 측정 관련 문제풀이 - 풀이 (6~10번)

## 문제 6: 줄의 길이 ✓

**풀이:**
```
240 ÷ 6 = 40
```

**정답: 40cm**

**설명:**
전체 길이를 같은 개수로 나누므로 나눗셈을 사용합니다.

---

## 문제 7: 시간 계산 ✓

**풀이:**
```
1단계) 120분을 시간으로 변환: 120 ÷ 60 = 2시간
2단계) 14시 30분 + 2시간 = 16시 30분 (오후 4시 30분)
```

**정답: 오후 4시 30분 (또는 16:30)**

**설명:**
분을 시간으로 바꿀 때는 60으로 나눕니다.
(1시간 = 60분)

---

## 문제 8: 무게 계산 ✓

**풀이:**
```
1단계) 전체 무게: 200 × 8 = 1600g
2단계) g을 kg으로 변환: 1600 ÷ 1000 = 1.6kg
        (또는 1kg 600g)
```

**정답: 1.6kg (또는 1kg 600g)**

**설명:**
1kg = 1000g 이므로, g을 kg으로 바꿀 때는 1000으로 나눕니다.

---

## 문제 9: 거리 계산 ✓

**풀이:**
```
1단계) 1200을 1000으로 나누기: 1200 ÷ 1000 = 1 나머지 200
2단계) 결과: 1km 200m
```

**정답: 1km 200m**

**설명:**
1km = 1000m 이므로, 1200m = 1km + 200m입니다.

---

## 문제 10: 용량 계산 ✓

**풀이:**
```
1단계) 전체: 200 × 5 = 1000mL
2단계) mL을 L로 변환: 1000 ÷ 1000 = 1L
```

**정답: 1L**

**설명:**
1L = 1000mL 이므로, mL을 L로 바꿀 때는 1000으로 나눕니다.

---

## 📏 단위 변환 정리

| 변환 | 공식 |
|------|------|
| 분 → 시간 | ÷ 60 |
| 시간 → 분 | × 60 |
| g → kg | ÷ 1000 |
| kg → g | × 1000 |
| m → km | ÷ 1000 |
| km → m | × 1000 |
| mL → L | ÷ 1000 |
| L → mL | × 1000 |
