# 기초 문제풀이 - 풀이 (1~5번)

## 문제 1: 과자 나누기 ✓

**풀이:**
```
48 ÷ 4 = 12
```

**정답: 12개**

**설명:** 
전체 48개를 4명이 똑같이 나눠 가지므로, 나눗셈을 사용합니다.

---

## 문제 2: 학용품 구매 ✓

**풀이:**
```
800 × 12 = 9600
```

**정답: 9600원**

**설명:**
연필 1개가 800원이고, 12개를 사므로 곱셈을 사용합니다.

---

## 문제 3: 책 읽기 ✓

**풀이:**
```
30 × 7 = 210
```

**정답: 210페이지**

**설명:**
매일 30페이지씩, 7일 동안이므로 30에 7을 곱합니다.

---

## 문제 4: 돈 계산 ✓

**풀이:**
```
10000 - 3500 = 6500
```

**정답: 6500원**

**설명:**
가진 돈에서 쓴 돈을 빼서 남은 돈을 구합니다.

---

## 문제 5: 우유 배달 ✓

**풀이:**
```
2000 × 25 = 50000
```

**정답: 50000원**

**설명:**
우유 1팩이 2000원이고, 25팩을 주문하므로 곱셈을 사용합니다.

---
